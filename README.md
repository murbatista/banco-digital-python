
# Sistema Bancário em Python

Projeto desenvolvido como parte do desafio da DIO, com o objetivo de praticar lógica de programação e funções em Python.

## Funcionalidades

- Depósito de valores
- Saque com limite de valor
- Limite de três saques
- Consulta de extrato
- Validação de entradas
- Menu interativo

## Tecnologias utilizadas

- Python 3

## Como executar

1. Instale o Python 3.
2. Baixe o arquivo `sistema_bancario.py`.
3. Execute o arquivo pelo terminal:

```bash
python sistema_bancario.py
```

## Objetivo

Praticar funções, condicionais, listas, tratamento de erros e estruturas de repetição em Python.
